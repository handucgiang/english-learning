# Từ vựng: Giao tiếp số & An toàn trực tuyến

| Từ / Cụm từ | Nghĩa | Ví dụ |
|---|---|---|
| **CC / BCC** | đồng gửi / đồng gửi ẩn (email) | Please *CC* my manager on this email. |
| **thread (email/chat)** | chuỗi tin nhắn/email | I lost track of this *thread* — can you summarize? |
| **video call** | cuộc gọi video | We had a *video call* to discuss the project. |
| **mute / unmute** | tắt / bật tiếng | You're on mute — please *unmute* yourself. |
| **screen share** | chia sẻ màn hình | Let me *screen share* to show you the report. |
| **phishing** | lừa đảo trực tuyến (giả mạo) | Don't click links from *phishing* emails. |
| **two-factor authentication (2FA)** | xác thực hai yếu tố | Enable *two-factor authentication* for extra security. |
| **password manager** | trình quản lý mật khẩu | I use a *password manager* to store my logins. |
| **privacy settings** | cài đặt quyền riêng tư | Check your *privacy settings* on social media. |
| **malware** | phần mềm độc hại | The file contained *malware*. |
| **firewall** | tường lửa | The company uses a *firewall* to block unauthorized access. |
| **encrypt / encryption** | mã hóa | All messages are protected by *encryption*. |
| **scam** | lừa đảo | She almost fell for an online *scam*. |
| **verify (identity)** | xác minh (danh tính) | You'll need to *verify* your identity to log in. |
| **data privacy** | quyền riêng tư dữ liệu | *Data privacy* is a growing concern for users. |

## Bài tập nhỏ

1. Never click links from suspicious emails — it could be a ______ attempt.
2. I use a ______ so I don't have to remember dozens of passwords.
3. You should enable ______ for extra account security.
4. Can you ______ so we can all see the same report?
5. Make sure to check your ______ before posting anything personal online.
