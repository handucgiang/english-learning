# Từ vựng: Ăn uống

| Từ / Cụm từ | Nghĩa | Ví dụ |
|---|---|---|
| **appetizer** | món khai vị | We ordered an *appetizer* to share. |
| **main course** | món chính | The *main course* was grilled salmon. |
| **dessert** | món tráng miệng | I always save room for *dessert*. |
| **reservation** | đặt bàn/đặt chỗ | I made a *reservation* for two at 7 p.m. |
| **bill / check** | hóa đơn | Can we get the *check*, please? |
| **tip** | tiền boa | We left a 15% *tip* for the waiter. |
| **takeout / delivery** | mang đi / giao hàng | Let's just order *takeout* tonight. |
| **spicy / bland** | cay / nhạt | This dish is too *spicy* for me. |
| **allergic to** | dị ứng với | I'm *allergic to* peanuts. |
| **recipe** | công thức nấu ăn | She shared her *recipe* for the cake. |
| **ingredient** | nguyên liệu | Fresh *ingredients* make a big difference. |
| **leftovers** | đồ ăn thừa | I'll save the *leftovers* for tomorrow. |
| **on a diet** | đang ăn kiêng | He's *on a diet* to lose weight. |
| **well done / rare** | chín kỹ / tái | I'd like my steak *well done*, please. |
| **treat someone to** | mời/đãi ai đó | Let me *treat you to* dinner tonight. |

## Bài tập nhỏ

Điền từ thích hợp:

1. Could we see the menu? We'd like to order an ______ first.
2. I can't eat shrimp — I'm ______ shellfish.
3. Let's ask for the ______; I think we're done eating.
4. He's ______ so he only eats salads these days.
5. This soup tastes a bit ______; can I have some pepper?
