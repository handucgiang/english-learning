## 1. Từ vựng cơ bản

| Từ / Cụm từ | Nghĩa | Ví dụ |
|---|---|---|
| **device** | thiết bị | I have too many *devices* charging at once. |
| **upgrade** | nâng cấp | I need to *upgrade* my laptop's memory. |
| **backup** | sao lưu | Always keep a *backup* of your important files. |
| **glitch** | lỗi nhỏ (kỹ thuật) | There's a *glitch* in the app that crashes it sometimes. |
| **user-friendly** | dễ sử dụng | The new interface is much more *user-friendly*. |
| **troubleshoot** | khắc phục sự cố | Our IT team helped *troubleshoot* the network issue. |
| **cloud storage** | lưu trữ đám mây | I keep all my photos in *cloud storage*. |
| **cybersecurity** | an ninh mạng | The company invested heavily in *cybersecurity*. |
| **artificial intelligence (AI)** | trí tuệ nhân tạo | *Artificial intelligence* is changing many industries. |
| **install / uninstall** | cài đặt / gỡ cài đặt | Please *install* the latest update. |
| **bandwidth** | băng thông | Video calls use a lot of *bandwidth*. |
| **outdated** | lỗi thời | This software is *outdated* and needs replacing. |
| **streamline** | tinh gọn, tối ưu (quy trình) | The new tool helps *streamline* our workflow. |
| **breach (data breach)** | rò rỉ/xâm phạm dữ liệu | The company suffered a major data *breach* last year. |
| **automate** | tự động hóa | We're trying to *automate* repetitive tasks. |

## 2. Phần cứng & Thiết bị (Hardware)

| Từ / Cụm từ | Nghĩa | Ví dụ |
|---|---|---|
| **hardware** | phần cứng | The issue seems to be with the *hardware*, not the software. |
| **motherboard** | bo mạch chủ | The *motherboard* needs to be replaced. |
| **processor / CPU** | bộ xử lý trung tâm | This laptop has a very fast *processor*. |
| **RAM / memory** | bộ nhớ tạm (RAM) | More *RAM* would make this computer faster. |
| **hard drive** | ổ cứng | My *hard drive* is almost full. |
| **SSD** | ổ cứng thể rắn | Switching to an *SSD* made booting much faster. |
| **GPU (graphics card)** | card đồ họa | Gamers usually need a powerful *GPU*. |
| **monitor / screen** | màn hình | I bought a second *monitor* for work. |
| **keyboard / mouse** | bàn phím / chuột | My *keyboard* has a few sticky keys. |
| **webcam** | camera trực tuyến | My *webcam* stopped working during the call. |
| **microphone (mic)** | micro | Can you check your *microphone*? I can't hear you. |
| **speaker** | loa | The *speakers* on this laptop are surprisingly good. |
| **printer / scanner** | máy in / máy quét | The office *printer* is out of ink again. |
| **router** | bộ định tuyến (wifi) | Restarting the *router* usually fixes the connection. |
| **modem** | bộ điều giải (modem) | The *modem* connects your home to the internet provider. |
| **cable** | dây cáp | This *cable* isn't long enough to reach the desk. |
| **port** | cổng kết nối | This laptop only has one USB *port*. |
| **USB drive / flash drive** | ổ đĩa USB | I saved the files on a *USB drive*. |
| **external hard drive** | ổ cứng di động | I back up everything to an *external hard drive*. |
| **docking station** | trạm kết nối (cho laptop) | The *docking station* lets me connect multiple monitors. |
| **adapter** | bộ chuyển đổi | I need an *adapter* to charge my phone abroad. |
| **touchpad** | bàn di chuột | The *touchpad* on this laptop feels very responsive. |

## 3. Phần mềm & Ứng dụng (Software)

| Từ / Cụm từ | Nghĩa | Ví dụ |
|---|---|---|
| **software** | phần mềm | We need to update the *software* on all computers. |
| **application (app)** | ứng dụng | I use a budgeting *app* to track expenses. |
| **operating system (OS)** | hệ điều hành | Which *operating system* does your laptop run? |
| **interface** | giao diện | The new *interface* is much cleaner. |
| **feature** | tính năng | This *feature* lets you edit photos directly in the app. |
| **function** | chức năng | I'm not sure what this *function* does. |
| **setting** | cài đặt | You can change the language in the *settings*. |
| **default** | mặc định | The *default* font is hard to read, so I changed it. |
| **license** | giấy phép (sử dụng phần mềm) | You need a valid *license* to use this software. |
| **freeware / open-source** | phần mềm miễn phí / mã nguồn mở | This is a free, *open-source* alternative. |
| **plug-in / add-on** | tiện ích mở rộng | I installed a *plug-in* to block ads. |
| **extension (browser)** | tiện ích mở rộng trình duyệt | This browser *extension* saves passwords automatically. |
| **template** | mẫu có sẵn | I used a *template* to design the slides quickly. |
| **toolbar** | thanh công cụ | The formatting options are in the *toolbar*. |
| **dashboard** | bảng điều khiển | You can see all your stats on the *dashboard*. |
| **widget** | tiện ích nhỏ (trên màn hình) | I added a weather *widget* to my home screen. |
| **interface (GUI)** | giao diện đồ họa người dùng | The app's *GUI* is simple and intuitive. |

## 4. Hoạt động công nghệ thường ngày (Common Tech Actions)

| Từ / Cụm từ | Nghĩa | Ví dụ |
|---|---|---|
| **sync / synchronize** | đồng bộ hóa | Make sure your phone is *synced* with your laptop. |
| **restart / reboot** | khởi động lại | Try *restarting* your computer first. |
| **shut down** | tắt máy | Remember to *shut down* your computer before leaving. |
| **log in / log out** | đăng nhập / đăng xuất | I forgot to *log out* of my account on that computer. |
| **sign up** | đăng ký (tài khoản) | You need to *sign up* before you can download it. |
| **configure** | cấu hình, thiết lập | The technician *configured* the new printer for us. |
| **customize** | tùy chỉnh | You can *customize* the app's appearance. |
| **format (a drive)** | định dạng (ổ đĩa) | I accidentally *formatted* the wrong drive. |
| **compress / zip** | nén (tệp) | *Compress* the files before emailing them. |
| **extract / unzip** | giải nén | *Extract* the files after downloading the zip folder. |
| **drag and drop** | kéo và thả | Just *drag and drop* the file into the folder. |
| **copy / paste** | sao chép / dán | *Copy* the text and *paste* it into the document. |
| **scroll** | cuộn (trang) | *Scroll* down to see more results. |
| **zoom in / zoom out** | phóng to / thu nhỏ | *Zoom in* to see the details more clearly. |
| **toggle** | bật/tắt (chuyển đổi) | *Toggle* dark mode on or off in the settings. |
| **enable / disable** | bật / tắt (tính năng) | *Disable* notifications while you're working. |
| **reset** | đặt lại | *Reset* your password if you forgot it. |
| **calibrate** | hiệu chỉnh | You may need to *calibrate* the screen's colors. |
| **optimize** | tối ưu hóa | We *optimized* the app to load faster. |
| **refresh** | làm mới (trang/trạng thái) | *Refresh* the page to see the latest updates. |
| **connect / disconnect** | kết nối / ngắt kết nối | The device keeps *disconnecting* from Wi-Fi. |

## 5. Ngành công nghệ & Kinh doanh công nghệ (Tech Industry)

| Từ / Cụm từ | Nghĩa | Ví dụ |
|---|---|---|
| **launch (a product)** | ra mắt (sản phẩm) | The company will *launch* its new phone next month. |
| **release** | phát hành | They *released* a major update yesterday. |
| **beta version** | phiên bản thử nghiệm | We're testing the *beta version* before the full release. |
| **prototype** | bản mẫu thử nghiệm | The team built a working *prototype* in two weeks. |
| **patent** | bằng sáng chế | The company holds several *patents* for this technology. |
| **innovation / innovative** | sự đổi mới / mang tính đổi mới | The startup is known for its *innovative* products. |
| **disruptive (technology)** | mang tính đột phá, gây xáo trộn | Ride-sharing apps were a *disruptive* technology. |
| **proprietary** | độc quyền, sở hữu riêng | This is *proprietary* technology owned by the company. |
| **tech giant** | tập đoàn công nghệ lớn | The *tech giant* announced record profits this quarter. |
| **market share** | thị phần | The company's *market share* has grown steadily. |
| **user base** | lượng người dùng | The app has a growing *user base*. |
| **adoption rate** | tỷ lệ áp dụng, chấp nhận sử dụng | The *adoption rate* for the new system was slower than expected. |
| **roadmap** | lộ trình phát triển | The product *roadmap* includes several new features. |
| **rollout** | triển khai (dần dần) | The full *rollout* will happen over several weeks. |
| **iteration** | phiên bản cải tiến (từng bước) | Each *iteration* of the product gets a bit better. |

## 6. Hỗ trợ kỹ thuật & Sự cố (Tech Support & Issues)

| Từ / Cụm từ | Nghĩa | Ví dụ |
|---|---|---|
| **technical support (tech support)** | hỗ trợ kỹ thuật | Contact *technical support* if the issue continues. |
| **error message** | thông báo lỗi | I got an *error message* when I tried to save the file. |
| **crash** | (phần mềm) bị sập, treo | The app *crashed* right in the middle of the call. |
| **freeze** | bị đơ, đứng máy | My screen *froze* and I had to restart. |
| **lag** | giật, trễ (khi thao tác) | The game *lags* whenever too many people are online. |
| **downtime / uptime** | thời gian ngừng hoạt động / hoạt động | The server had two hours of *downtime* last night. |
| **patch** | bản vá lỗi | They released a *patch* to fix the security issue. |
| **fix** | bản sửa lỗi, khắc phục | A *fix* for this bug should be out next week. |
| **workaround** | giải pháp tạm thời | There's a *workaround* until the bug is officially fixed. |
| **compatibility issue** | vấn đề tương thích | We're having *compatibility issues* with the older devices. |
| **driver** | trình điều khiển (thiết bị) | You may need to update the *driver* for your printer. |
| **diagnostic** | chẩn đoán (kỹ thuật) | Run a *diagnostic* test to find the problem. |
| **root cause** | nguyên nhân gốc rễ | We finally identified the *root cause* of the crash. |

## 7. Tính từ mô tả công nghệ

| Từ / Cụm từ | Nghĩa | Ví dụ |
|---|---|---|
| **intuitive** | trực quan, dễ hiểu | The app's design is very *intuitive*. |
| **seamless** | liền mạch, mượt mà | The transition between devices is *seamless*. |
| **robust** | mạnh mẽ, ổn định | The system is *robust* enough to handle heavy traffic. |
| **cutting-edge** | tiên tiến nhất, đi đầu | This lab uses *cutting-edge* technology. |
| **state-of-the-art** | hiện đại nhất, tối tân | The factory uses *state-of-the-art* equipment. |
| **glitchy** | hay bị lỗi vặt | The app has been *glitchy* since the last update. |
| **buggy** | nhiều lỗi (phần mềm) | Early versions of the software were quite *buggy*. |
| **responsive** | phản hồi nhanh, nhạy | The website is fully *responsive* on mobile. |
| **lightweight** | nhẹ (ít tài nguyên) | This is a *lightweight* app that won't slow your phone down. |
| **high-tech / low-tech** | công nghệ cao / công nghệ đơn giản | It's a surprisingly *low-tech* solution to a complex problem. |
| **hands-free** | rảnh tay | These headphones offer *hands-free* calling. |
| **plug-and-play** | cắm là chạy (không cần cài đặt) | The device is *plug-and-play* — no setup required. |
| **energy-efficient** | tiết kiệm năng lượng | The new chip is far more *energy-efficient*. |
| **obsolete** | lỗi thời, không còn dùng | This format is now *obsolete*. |
| **scalable** | có thể mở rộng | We need a more *scalable* infrastructure. |
