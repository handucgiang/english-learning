# Từ vựng: Lập trình & Phát triển phần mềm

| Từ / Cụm từ | Nghĩa | Ví dụ |
|---|---|---|
| **code / coding** | mã nguồn / lập trình | She spends most of her day *coding*. |
| **bug** | lỗi phần mềm | The team is fixing a *bug* in the login page. |
| **debug** | gỡ lỗi | It took hours to *debug* the issue. |
| **deploy / deployment** | triển khai | We *deployed* the new update last night. |
| **repository (repo)** | kho lưu trữ mã nguồn | Push your changes to the *repository*. |
| **version control** | quản lý phiên bản | Git is a popular *version control* tool. |
| **commit** | ghi lại thay đổi (trong Git) | I forgot to write a message for that *commit*. |
| **merge (branches)** | hợp nhất (nhánh mã) | We need to *merge* this branch into main. |
| **framework** | khung phát triển (phần mềm) | The app was built using a popular JavaScript *framework*. |
| **API (Application Programming Interface)** | giao diện lập trình ứng dụng | The app connects to a weather *API*. |
| **front-end / back-end** | giao diện người dùng / phía máy chủ | She specializes in *front-end* development. |
| **database** | cơ sở dữ liệu | All user data is stored in the *database*. |
| **server** | máy chủ | The *server* went down for an hour last night. |
| **release notes** | ghi chú phát hành (bản cập nhật) | Check the *release notes* for what's new. |
| **scalable** | có khả năng mở rộng | We need a more *scalable* solution for growth. |

## Bài tập nhỏ

1. There's a ______ in the checkout process that's causing errors.
2. We use Git for ______ so everyone can track changes.
3. The app connects to an external ______ to get weather data.
4. All the user information is stored in the ______.
5. Our current system isn't very ______ — it slows down with more users.
