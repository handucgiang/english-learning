# Kỹ năng Đọc: Đoán nghĩa từ qua Cấu tạo từ (Prefixes, Suffixes, Roots)

Ngoài kỹ thuật đoán nghĩa từ ngữ cảnh ở [01-reading-strategies.md](01-reading-strategies.md), một công cụ mạnh khác là phân tích **cấu tạo từ** — phần lớn từ vựng tiếng Anh (đặc biệt từ học thuật) được ghép từ tiền tố, hậu tố, và gốc từ Latin/Hy Lạp có nghĩa cố định.

## 1. Tiền tố (Prefixes) — thường thay đổi NGHĨA của từ

| Tiền tố | Nghĩa | Ví dụ |
|---|---|---|
| un-, in-, im-, dis-, non- | phủ định, không | unhappy, incomplete, impossible, disagree, nonsense |
| re- | lại, làm lại | rewrite, rebuild, review |
| pre- | trước | preview, prepare, predict |
| post- | sau | postpone, postwar |
| over- | quá mức | overwork, overeat |
| under- | thiếu, dưới mức | underestimate, underpaid |
| mis- | sai, nhầm | misunderstand, mislead |
| anti- | chống lại | antivirus, antisocial |
| co-, con-, com- | cùng nhau | cooperate, connect, combine |
| trans- | xuyên qua, chuyển đổi | transport, transform |
| inter- | giữa, liên | international, interact |
| sub- | dưới | submarine, subway |
| super- | trên, vượt | superhuman, supervise |
| multi- | nhiều | multitask, multicultural |
| semi- | nửa | semicircle, semifinal |

## 2. Hậu tố (Suffixes) — thường thay đổi LOẠI TỪ

| Hậu tố | Loại từ tạo thành | Ví dụ |
|---|---|---|
| -tion, -sion, -ment, -ness, -ity | danh từ | creation, decision, development, happiness, activity |
| -er, -or, -ist | danh từ (người thực hiện hành động) | teacher, actor, scientist |
| -able, -ible | tính từ (có thể...) | readable, flexible |
| -ful | tính từ (đầy, có tính chất) | helpful, careful |
| -less | tính từ (không có) | hopeless, careless |
| -ive, -al, -ic | tính từ | active, national, economic |
| -ly | trạng từ | quickly, carefully |
| -ize, -ise | động từ (làm cho...) | realize, modernize |
| -en | động từ (làm cho...) | strengthen, widen |

**Ví dụ ứng dụng:** gặp từ lạ **"unreadable"** → un- (không) + read (đọc) + -able (có thể) = "không thể đọc được".

## 3. Gốc từ Latin/Hy Lạp thường gặp

| Gốc từ | Nghĩa | Ví dụ |
|---|---|---|
| dict | nói | predict, dictionary, contradict |
| port | mang, chở | transport, import, export |
| scrib/script | viết | describe, manuscript, subscribe |
| spect | nhìn | inspect, respect, spectator |
| struct | xây dựng | construct, structure, instruct |
| vis/vid | nhìn thấy | visible, video, vision |
| ject | ném, quăng | reject, project, inject |
| duc/duct | dẫn dắt | introduce, conduct, produce |
| bio | sự sống | biology, biography |
| chrono | thời gian | chronological, synchronize |
| geo | trái đất | geography, geology |
| phon | âm thanh | telephone, phonetics |

## 4. Cách ứng dụng khi đọc

Gặp một từ dài, lạ, thử tách thành từng phần:

**Ví dụ:** "The new policy was designed to be **irreversible**."

- ir- (phủ định) + revers(e) (đảo ngược) + -ible (có thể) = "không thể đảo ngược"

**Ví dụ khác:** "The company's **transcontinental** operations expanded rapidly."

- trans- (xuyên qua) + continent (lục địa) + -al (tính từ) = "xuyên lục địa"

## 5. Bài tập

Dùng cấu tạo từ để đoán nghĩa các từ sau, không tra từ điển:

1. **misinterpret**
2. **overqualified**
3. **biography**
4. **inspector**
5. **irreplaceable**
6. **multinational**

<details>
<summary>Đáp án</summary>

1. misinterpret = mis- (sai) + interpret (diễn giải) = hiểu sai, diễn giải sai
2. overqualified = over- (quá mức) + qualified (đủ trình độ) = quá trình độ so với yêu cầu
3. biography = bio- (sự sống) + -graphy (viết) = tiểu sử
4. inspector = in- + spect (nhìn) + -or (người) = thanh tra viên (người kiểm tra)
5. irreplaceable = ir- (phủ định) + replace (thay thế) + -able (có thể) = không thể thay thế
6. multinational = multi- (nhiều) + national (quốc gia) = đa quốc gia

</details>
