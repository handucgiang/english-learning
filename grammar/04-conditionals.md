# Ngữ pháp: Câu điều kiện (Conditionals)

## Loại 0 — Sự thật hiển nhiên

**Công thức:** If + S + V(hiện tại đơn), S + V(hiện tại đơn)

**Ví dụ:**
- If you *heat* water to 100°C, it *boils*.

## Loại 1 — Có thể xảy ra ở hiện tại/tương lai

**Công thức:** If + S + V(hiện tại đơn), S + will + V

**Ví dụ:**
- If it *rains* tomorrow, we *will cancel* the picnic.
- If you *study* hard, you *will pass* the exam.

## Loại 2 — Giả định trái với hiện tại (không có thật)

**Công thức:** If + S + V2/ed (were với "to be"), S + would + V

**Ví dụ:**
- If I *were* rich, I *would travel* around the world. (thực tế: tôi không giàu)
- If she *knew* the answer, she *would tell* you.

## Loại 3 — Giả định trái với quá khứ (không có thật, đã qua)

**Công thức:** If + S + had + V3/ed, S + would have + V3/ed

**Ví dụ:**
- If I *had studied* harder, I *would have passed* the exam. (thực tế: đã không học chăm và đã trượt)
- If they *had left* earlier, they *wouldn't have missed* the flight.

## Câu điều kiện hỗn hợp (Mixed Conditional) — nâng cao

**Dùng khi:** giả định quá khứ nhưng ảnh hưởng đến hiện tại.

**Ví dụ:**
- If I *had taken* that job, I *would be* living in Singapore now.

## So sánh nhanh

| Loại | Tình huống | Mệnh đề IF | Mệnh đề chính |
|---|---|---|---|
| 0 | Sự thật | V hiện tại | V hiện tại |
| 1 | Có thể xảy ra | V hiện tại | will + V |
| 2 | Giả định hiện tại (không thật) | V2/ed, were | would + V |
| 3 | Giả định quá khứ (không thật) | had + V3 | would have + V3 |

## Bài tập

Chia động từ đúng:

1. If it ______ (rain), the streets get wet. (loại 0)
2. If I ______ (have) more time, I will finish the project today. (loại 1)
3. If I ______ (be) you, I would apologize. (loại 2)
4. If she ______ (study) harder, she would have passed the exam. (loại 3)
5. If we leave now, we ______ (not/miss) the train. (loại 1)

<details>
<summary>Đáp án</summary>

1. rains
2. have
3. were
4. had studied
5. will not miss / won't miss
