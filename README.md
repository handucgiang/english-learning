## Cách dùng gợi ý

1. **Từ vựng**: đọc theo chủ đề, tự đặt câu mới với mỗi từ ngoài câu ví dụ có sẵn.
2. **Ngữ pháp**: đọc quy tắc → xem ví dụ → làm bài tập cuối mỗi file → tự đối chiếu đáp án (để cuối file, không nhìn trước).
3. **Mẫu câu**: học theo tình huống, luyện nói to từng câu, không chỉ đọc thầm.

Bạn có thể yêu cầu tôi bổ sung thêm chủ đề mới hoặc mở rộng file bất kỳ lúc nào.
