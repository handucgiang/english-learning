# Kỹ năng Nghe: Ghi chú nhanh khi nghe (Note-taking)

Khi nghe bài giảng, cuộc họp, hoặc hội thoại dài, bạn không có thời gian viết đầy đủ câu. Dùng ký hiệu viết tắt giúp ghi kịp tốc độ nói.

## 1. Ký hiệu toán học / logic thường dùng

| Ký hiệu | Ý nghĩa |
|---|---|
| → | dẫn đến, kết quả là |
| ← | do bởi, nguyên nhân từ |
| ↑ | tăng |
| ↓ | giảm |
| = | là, bằng |
| ≠ | không phải là, khác |
| + | và, thêm vào |
| ∴ | vì vậy |
| ∵ | bởi vì |
| ? | chưa chắc chắn, cần kiểm tra lại |
| w/ | with (với) |
| w/o | without (không có) |
| b/c | because (bởi vì) |
| b/4 | before (trước) |
| btw | between (giữa) |
| etc | và những cái khác |
| e.g. | ví dụ |
| esp. | especially (đặc biệt) |
| info | information |
| govt | government |
| approx. | approximately (khoảng) |

## 2. Viết tắt bằng cách bỏ nguyên âm

Chỉ giữ phụ âm, dễ đọc lại đúng nghĩa:

- management → mgmt
- department → dept
- development → dvlpmnt
- important → impt
- necessary → nec
- number → no. hoặc #
- maximum / minimum → max / min

## 3. Cấu trúc ghi chú dạng cây (outline)

Không ghi thành câu đầy đủ — ghi theo cấp bậc ý chính/ý phụ:

```
Meeting: Q3 sales
- Revenue ↑ 12% vs Q2
  - driven by: new product line
  - weak region: SEA (↓ 5%)
- Action items
  - marketing → new campaign b/4 Oct
  - sales team → follow up top 10 clients
```

## 4. Mẹo khi ghi chú trong hội thoại/cuộc họp thực tế

- Ghi **số liệu, tên riêng, mốc thời gian** chính xác — đây là phần khó nhớ lại sau.
- Không cố ghi mọi câu — chỉ ghi ý chính và từ khóa, phần còn lại tái dựng lại bằng trí nhớ.
- Dùng dấu `?` bên cạnh chỗ nghe không chắc, để sau đó hỏi lại hoặc kiểm tra.
- Sau buổi nghe, dành 2–3 phút viết lại ghi chú thành câu hoàn chỉnh trong khi trí nhớ còn mới — giúp nhớ lâu hơn.

## 5. Bài tập

Viết lại các câu sau bằng ký hiệu viết tắt (dùng các ký hiệu ở mục 1-2):

1. "Revenue increased because of the new marketing campaign, therefore we should increase the budget."
2. "The department needs more staff before the deadline, especially in management."
3. "We are not sure about the number of clients, approximately 50, but we need to check."
